部署成功后，打开构建日志里的一次性链接：

```text
https://<store>.workers.dev/setup?token=...
```

## 创建管理员

Setup 页面只需要填写：

- 管理员姓名
- 登录邮箱
- 密码（至少 8 位，包含字母和数字）

商店名称和货币使用部署默认值，之后可以在后台修改。

创建成功后，Setup link **立即失效**。系统没有默认管理员密码。

## 建议的初始配置

按顺序完成下面几项，商店就可以开始营业：

1. **设置 → 店铺信息**：商店名称、邮箱、电话、地址
2. **设置 → 税费**：默认税率、是否含税、按国家/地区覆盖
3. **配送**：配送区域、运费、免运费门槛
4. **商品**：创建商品、上传/填写图片、设置库存
5. **主题**：选择一套主题，配置颜色和字体
6. **支付**：启用人工支付、Stripe 或 PayPal，并填写密钥
7. **邮件通知**（可选）：启用插件并配置发件通道
8. **页面**：完善 About、Contact、FAQ、隐私政策等草稿并发布

## 安全建议

- 使用强密码，不要与其他网站共用
- 不要把 Setup link 发给任何人
- 支付密钥只保存在加密的 D1 设置中，不会返回浏览器
- 修改密码后，其他后台会话会立即失效
