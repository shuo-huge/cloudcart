## 创建商品

进入 **后台 → Products → New product**，填写：

- 商品名称和 URL slug
- 描述（支持基础 HTML，渲染时消毒）
- 价格、划线价
- SKU、库存
- 是否管理库存
- 状态：草稿 / 上架 / 归档
- 分类和标签
- SEO 标题与描述

保存后商品会出现在后台列表和前台商品页。

## 商品图片

云商城默认使用 **HTTPS 图片外链**，不需要 R2。

在商品编辑页的 **Media** 区域：

1. 填写公开 HTTPS 图片地址，点击 **Add URL**
2. 可以添加多张图片
3. 拖拽图片调整顺序
4. 第一张图片自动成为商品封面

如果之后启用了 R2，也可以使用文件上传。默认部署不创建 R2。

## 规格（Variants）

商品类型选择 `variable` 后，可以添加多个规格，例如颜色、尺寸。每个规格可以有自己的：

- 标题
- SKU
- 价格
- 库存
- 启用状态

结账时会使用具体规格的价格和库存。

## 分类

**后台 → Categories**：

- 创建分类、设置名称和 slug
- 设置排序位置
- 可以设置父分类
- 商品可以属于多个分类

分类会出现在前台导航和分类页。

## 库存

如果开启库存管理，下单时 CloudCart 会在服务端用条件更新预占库存，避免超卖；订单创建失败时会补偿库存。

## 批量管理

商品列表支持分页、搜索和状态筛选。删除商品不会删除历史订单快照。
