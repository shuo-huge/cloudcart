title: 店铺设置
description: 店铺信息、密码、SEO、重定向、审计和资源用量。
---

**后台 → Settings** 集中管理店铺级配置。

## 店铺信息

- 商店名称
- 货币（ISO 4217，如 USD、CNY）
- 语言/地区（如 zh-CN、en-US）
- 客服邮箱
- 客服电话
- 业务地址
- Logo URL
- 公告栏文本

这些信息会用于前台页头、页脚、邮件和 SEO。

## 修改密码

输入当前密码和的新密码。新密码至少 8 位，包含字母和数字。

修改密码后，其他后台会话会立即失效。

## 税费

税费配置在 Settings 的 **Taxes** 卡片：

- 默认税种名称
- 默认税率
- 是否含税
- 国家/地区税率规则

详见 [运费与税费](/admin/shipping-tax/)。

## SEO

**后台 → SEO**：

- 默认标题
- 默认 Meta 描述
- 301 重定向

每个商品和分类还可以单独设置 SEO 标题与描述。

## 审计日志

记录管理员的关键操作：登录、商品修改、订单状态、插件启停、设置修改等。

## 资源用量

后台显示本地估算：

- API 请求数
- D1 读写
- R2 操作
- 媒体存储
- 商品/订单数量

这些是估算值，Cloudflare Dashboard 才是权威数据。

## 维护模式

可以设置维护公告。维护模式不会自动关闭结账，请谨慎使用。
