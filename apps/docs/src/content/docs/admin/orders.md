## 订单列表

**后台 → Orders** 显示订单号、客户、金额、支付状态、订单状态和时间。支持按状态、支付状态和关键词筛选。

## 订单详情

点击订单进入详情页，可以看到：

- 商品明细和金额
- 收货地址
- 客户备注和内部备注
- 支付交易记录
- 操作时间线
- 物流信息

## 人工付款

如果客户选择人工付款（银行转账、货到付款等）：

1. 确认实际收到款项
2. 点击 **Confirm payment**
3. 填写备注（可选）
4. 订单变为 `paid`

系统会记录确认管理员的 ID、时间和备注，并写入审计日志。

## 发货

填写：

- 承运商
- 物流单号
- 物流查询 URL（可选）

然后把订单状态改为 `shipped`。客户在订单页可以看到物流信息。

订单状态机由服务端强制校验，不允许非法跳转。

## 取消订单

取消订单会自动把预占的库存补回。状态菜单中的 `cancelled` 和「Cancel order & restock」按钮使用同一套补库存逻辑；重复或并发取消只会补回一次。已经支付的订单是否能取消取决于当前状态。退款会记录在支付状态和已退款金额中，不会阻止订单继续发货或完成。已取消、已退款或已履约的订单不能重新发起支付。

## 退款

支持记录退款：

- 人工支付：直接记录退款金额
- Stripe / PayPal：调用支付服务商退款接口，成功后记录
- 远程支付插件：调用插件的退款端点

退款不会删除订单和支付交易。部分退款会更新支付状态为 `partially_refunded` 和已退款金额，但不会改变订单履约状态。

## 退货

**订单详情 → Returns → Record return**：

- 选择商品和实际收到的数量；累计退货数量不能超过订购数量
- 可选择是否回补库存；回补会写入库存流水
- 可填写退货原因和内部备注

退货与退款分开：登记退货不会自动退款。

## 未付款订单自动关闭

在线支付订单如果超过 60 分钟仍未付款，后台定时任务会自动取消订单、回补库存并释放优惠券使用次数。人工付款订单不会被自动取消。

## 订单隐私

订单访问链接使用签名 token，客户不需要登录即可查看自己的订单。不要把订单链接公开分享。
