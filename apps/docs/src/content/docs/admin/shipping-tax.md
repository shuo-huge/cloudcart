title: 运费与税费
description: 配置配送区域、运费规则和国家/地区税率。
---

## 配送区域

**后台 → Shipping → Zones**：

- 区域名称
- 国家代码列表（如 `US, CA, GB`）
- 是否默认区域

当收货国家没有匹配区域时，会使用默认区域。

## 运费规则

每个区域可以配置多条运费：

- 运费名称
- 价格
- 最低订单金额
- 最高订单金额
- 满额免运费
- 是否启用

结账时 CloudCart 会根据收货地址和订单金额选择可用运费。

## 税费

**后台 → Settings → Taxes**：

- **税种名称**：例如 Sales tax、VAT
- **默认税率**：没有匹配规则时使用
- **商品价格含税**：开启后从展示价格中提取税费，而不是额外加收

### 税率规则

可以添加按国家/地区覆盖的规则：

| 字段 | 说明 |
|---|---|
| 名称 | 例如 California sales tax |
| 国家 | 两位 ISO 代码，如 US |
| 地区/州 | 可选；留空表示整个国家 |
| 税率 | 百分比，如 8.25 |
| 启用 | 是否生效 |

匹配顺序：

1. 国家 + 地区精确匹配
2. 国家级规则（地区留空）
3. 默认税率

### 计税基数

税费基于：

```text
max(0, 商品小计 - 折扣 + 运费)
```

- 不含税模式：税费额外加到订单总额
- 含税模式：从总额中提取税费，总额不变

税费会写入订单，并自动包含在支付金额中。

## 注意事项

- 当前版本不支持免税客户证明和按商品配置税类
- 修改税率不会影响历史订单
- 退款不会重新计算历史税费
